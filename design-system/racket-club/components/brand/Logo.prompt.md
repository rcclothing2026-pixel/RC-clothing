The Racket Club logo — mark + Mansory wordmark, drawn inline (no asset needed).

```jsx
<Logo />                                  {/* horizontal navy lockup */}
<Logo layout="stacked" showSlogan />       {/* centered + "Legend & Legacy" */}
<Logo layout="mark" tone="cream" size={64}/> {/* mark only, for dark bg */}
```
`layout`: `horizontal` `stacked` `mark` `wordmark`. `tone`: `navy` (on light) `cream` (on dark) `green`. `size` = mark height px.
