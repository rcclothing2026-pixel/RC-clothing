Racket Club action control — sharp corners, tracked label, heritage palette. The `accent` CTA carries the brand's clay→brown gradient.

```jsx
<Button variant="accent" size="lg">Add to bag</Button>
<Button variant="primary">Explore the collection</Button>
<Button variant="outline" leftIcon={<Icon name="search" />}>Search</Button>
```

Variants: `primary` (navy), `secondary` (forest green), `accent` (clay→brown gradient — main CTA), `gradient` (navy→forest primary gradient), `outline`, `ghost`.
Sizes: `sm` `md` `lg`. Props: `fullWidth`, `disabled`, `leftIcon`, `rightIcon`, plus native button attrs.
Use `accent` sparingly — one CTA per view.
